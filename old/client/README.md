# Legacy Gatsby frontend

This is the archived frontend formerly deployed on Netlify. The active Next.js
website and integrated admin are at the [repository root](../../README.md).

Run legacy commands from this directory using its `.nvmrc`, package manifest and
Yarn lockfile. Build scripts and the original Netlify configuration are retained.
The root Netlify configuration skips automatic builds to preserve the previous
deployment as a migration fallback.

The legacy Strapi backend is archived in [`../admin/`](../admin/).
Local dependencies, build caches and private credentials are not committed.
